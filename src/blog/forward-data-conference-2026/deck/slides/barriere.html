And here, we need to bust a myth: today, the barrier to entry for contributing to a repo is close to zero. These people don’t write code. They don’t even read the code. And they don’t type a single Git command. [clic] They simply converse with Claude: in VS Code, or directly in Claude Desktop. [clic] An example. A business project manager, who knows SAP and works with logistics, brought data from SAP into Snowflake, cleaned it up following our conventions, and built an operational dashboard tracking the logistics teams’ KPIs. In a single conversation. The agent handled Git, the branches and the code. And at the end of the conversation, the platform was richer.
