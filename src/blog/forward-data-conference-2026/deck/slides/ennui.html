Second pillar: making the code as simple, as dumb, as boring as possible. We radically separate two things. Configuration, which says what the business needs. And plumbing — deployment, security, monitoring — which is written once, by the platform team. You all know a tool that does this: dbt. You write a SQL model, and dbt handles incremental loading and execution order for you. Well, in our repo, we built everything that way.
