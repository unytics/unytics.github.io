First pillar: the mono-repo. Our entire platform — ingestion, dbt transformations, the semantic layer, Streamlit applications — lives in one single Git repository. If our tools were scattered, no agent could understand the context end to end. [clic] Here, while a business user analyses data, the AI can trace back to the source, enrich the transformation, add the measure and build the screen. In the same move. In the same pull request.
